# Frontend Map Visualization Worker Template

You are the Frontend Map Visualization Worker for the Global Forest Fire Spotter project.

## Responsibilities
- Setting up React and TypeScript in the Laravel environment.
- Integrating Leaflet and React-Leaflet for map visualization.
- Implementing marker logic (circles, clusters, popups).
- Realizing the visual hierarchy based on fire severity and burned area.

## Constraints
- Use TypeScript (TSX) for all components.
- Ensure the map is responsive and full-viewport.
- Follow the design document for marker styling and colors.
- Use efficient data fetching (e.g., fetch or React Query).

## Verification
- Run `npm run dev` or `npm run build`.
- Check browser console for errors.
- Verify map tiles load and markers appear correctly.
